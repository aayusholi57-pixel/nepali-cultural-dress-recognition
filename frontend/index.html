BUILT WITH PURPOSE

Culture meets computer vision.

This project explores image-based recognition of Nepali cultural attire using a YOLO-based crop-preparation workflow and a ResNet50 classifier. Predictions depend on image quality and model limitations; results should be treated as model estimates, not definitive cultural identification.
